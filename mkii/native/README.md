# 160 MKII 0.1 Native Windows x64 VST3

Install the entire `160 MKII.vst3` bundle. This build requires AVX2. The plugin reports 512 samples of latency for host blocks up to 256 samples. With a 512-sample host block, it reports 1,024 samples (23.2 ms at 44.1 kHz). Mono runs one circuit and stereo runs two independent circuits. Threshold, compression ratio, and output gain are available during playback. The default threshold is 0.2 V RMS, matching the native circuit’s initialization. Offline VST3 processing uses the same native circuit.

The plugin compiles the connected 160 retrofit deck into a modified nodal system, including the RC4558, THAT2181B and 4301RMS manufacturer models and the discrete BC341/BC361 output stage. It keeps the detector, coupling and driver charge histories. The solver generates specialized sparse elimination and linear residual schedules for 44.1, 48 and 96 kHz, and substeps difficult transients. It uses one in-process worker per channel and a fixed-size ring for the audio callback. During playback, the callback submits input and retrieves the delayed output. If a worker misses a deadline, that sample uses the delayed input and the interface indicates a processing miss.

ngspice runs during build preparation and reference testing. The native solver runs in-process from the runtime included inside the VST3 bundle. The circuit uses quiet rails and the reference’s 600 Ω load. A sample-rate-calibrated two-pole shelf compensates the fixed-step solver’s extra high-frequency loss at the wet circuit output. It targets the deck’s small-signal AC response and adds no buffered latency. The release checks cover raw solver SPICE parity at 1 kHz, VST3 small-signal response within ±1 dB from 30 Hz to 20 kHz at 44.1, 48 and 96 kHz, paced mono and stereo playback inside a Windows VST3 host at 44.1 and 48 kHz with 128-sample buffers, plus multitone and cymbal-like burst stress tests at 44.1 kHz with 512-sample buffers. The full parameter, oversampling, noisy-rail and hardware comparison matrix remains open.
