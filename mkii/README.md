# 160 MKII 0.1 offline Windows x64 VST3

Copy the entire `160 MKII.vst3` bundle into the DAW’s VST3 folder. Set threshold, compression ratio and output gain before an offline export or render. The host must signal offline processing. Live playback passes the input through. Stereo runs two independent circuits. Controls are fixed for the duration of a render. Keep the bundle resources with the VST3 binary.

The plug-in streams audio through a separate ngspice process per channel. That process solves the connected `circuit/160_retrofit.cir` deck using the factory RC4558, THAT2181B and 4301 macromodels and the repository’s BC341 and BC361 models. It keeps the detector, coupling and output-stage state across host blocks. The build replaces the two built-in sine sources with balanced piecewise-linear audio and selects the same quiet-rail option used in the reference tests. It uses the deck’s 600 Ω load. A −18 dBFS peak sine maps to +4 dBu RMS differential. The simulation runs 50 ms of silence before the first audio sample and takes Gear steps of up to 2.5 µs.

The build compares a 1 kHz waveform against the original deck driven by the same PWL samples at 44.1 kHz. The report includes phase, K2–K20, THD and render speed. The Windows smoke test loads the built plug-in and exercises mono and stereo offline rendering. The connected deck is a retrofit candidate. Original 160VU module and meter circuitry, unconnected schematic drafts, noisy-rail operation, the full measurement matrix and live real-time performance are outside this preview’s verified coverage. The transient command is limited to one hour and ngspice retains its saved vectors during the render.
